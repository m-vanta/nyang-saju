# 냥도사의 천기누설 (냥사주)

1,900원짜리 고양이 도사 종합 운세 모바일 웹앱입니다. 생년월일시를 입력하면 **실제 만세력 엔진(`@fullstackfamily/manseryeok` 1.3.0, 한국천문연구원 음양력·절입 자료)** 으로 사주명식(년주·월주·일주·시주)·오행 분포·십신·12운성·지장간·대운을 세웁니다.

**무료**에서는 여덟 단계로 ① 일간×오행 분포×십성으로 만든 **팔자 고양이 캐릭터** ② **캐릭터명·대표 키워드** ③ **천기팩폭 1개** ④ **대표 성향 핵심 3** ⑤ **결과 카드 PNG 공유**(9:16·1:1) ⑥ **사주명식·오행 분포**(접기) ⑦ **연애·재물·직업운 맛보기와 결제 버튼** ⑧ **인연 궤도**(관계 특성·친구 초대)를 엽니다.

**복채 1,900원(지금은 미리보기 결제)** 을 내면 ① 연애·재물·직업운 전체 풀이(고른 운세 먼저) ② 천기팩폭 심층·대표 성향 상세 ③ 반복되는 인생 패턴 3개 ④ 인연 궤도 상세 관계 해석 ⑤ 나만의 천기부적 PNG 가 열립니다.

- **컨셉**: `냥도사의 천기누설` — 예의 바르지만 뼈를 때리는 고양이 도사. 결과는 **본편(사주 전체 해석) → 한 겹 더(시선 풀이·인연 궤도)** 두 층으로 나뉩니다. 본편에서 타고난 기질·돈과 일·물어본 질문·타이밍을 다 풀고, 한 겹 더에서 내가 나를 보는 시선, 사람들이 나를 보는 시선, 곁에 둘 기운과 피할 기운, 그리고 **나를 중심으로 친구들이 달 궤도처럼 도는 인연 지도**를 얹습니다.
- **말투**: `민지 님` 호칭 하나, 2인칭은 전부 `{name} 님`(`당신`·반말·`집사` 0건). **냥도사 말투(`~냥`)는 캐릭터가 직접 쓴 말 — 천기팩폭·천기부적 — 에만** 씁니다. 메인 카피·로딩·결제 모달·궤도 안내를 포함한 모든 안내와 사주 상세 해설은 **자연스러운 해요체(`~예요`·`~해요`)** 로만 쓰고, 문장 끝에 `~냥`을 기계적으로 붙이지 않으며 `~입니다`·`~하세요`를 섞지 않습니다. 결제·안내 문구는 짧은 일반 문체(`복채 1,900원으로 전체 풀이 보기`)입니다.
- **문장 두 집**: 화면에 고정으로 박히는 라벨·안내는 `index.html`, JS가 갈아끼우는 문장(로딩·토스트·결과 섹션·명식 해설·부적 카드)과 일간 10종 천기는 `copy.js`.

## 0. v2.4 개선 (2026-11-25) — 판독을 사실로 · 물상 일러스트 · 비교 하네스

### 0-A. `analysisData` — 판정을 만들지 않는 구조화 사실

`src/domain/analysis.js` 가 명식에서 **사실만** 뽑습니다. 격국 확정·득령/득지/득세 합산·용신 판정은 넣지 않았습니다.

- **득령·득지·득세는 각각 독립 판독**: 오행 생조(방향까지) · 왕상휴수사 · 12운성(표 기준 강집합) · 본기 십성. `supported` 같은 단일 boolean 으로 접는 필드는 린트가 거부합니다.
- **통근**: 지지별 지장간을 重/輕 두 등급으로 나열(`rootGrade`). 長生祿旺=重, 그 밖=輕.
- **격국**: 본기·투출·회국·祿/刃 후보를 **모두** 내고 `agreement(same|partial|differs|none)` 만 기록. `decided:false` 고정.
- **합충**: 천간합·천간충·육합·육충·형·파·해·삼합/반합. 合化는 `transform.possible` 까지만, `decided:false`.

## 0-2. v2.3 구조 개선 (2026-11-25)

계산·판정·문장·렌더를 4층으로 나눴습니다. 화면 디자인과 팔자 고양이 10종, 브랜드 세계관은 그대로입니다.

```
src/domain/   출생 입력 → 명식(chart.js) · 조회 시점 → 세운·대운(period.js) · 궁합
src/rules/    명식 → Finding[] (오행 개수·동률, 십성, 지장간, 합·충·형·파·해, 월령)
src/content/  free.js · paid.js 문장 카탈로그 (requires/forbids)
src/render/   Finding → 문장 선택 + 근거 칩 자동 생성
```

- **세운은 입춘 절입 순간**에 바뀝니다(1/1 아님). 연주 기반 덧셈 오류를 없앴습니다.
- **대운**은 천간·지지를 따로 판정하고, 출생+대운수(3일=1년) 날짜부터 10년씩 계산합니다.
- **자시**는 야자시/조자시를 입력에서 고르고, 절입이 시진 안에 있으면 고지합니다.
- **서머타임**(1948~51·1955~60·1987~88)과 1954~61 UTC+8:30을 법정 시계로 보정합니다.
- **오행 동률**은 공동 최강으로 표시하고, 같은 개수는 같은 %로 배분합니다(최대잔여법 제거).
- **시간 미상**은 6글자로 끝까지 표기하고 정오 가정을 고지합니다.
- **근거 칩**은 문장의 `requires` Finding에서만 자동 생성됩니다(`basisFor` 삭제).
- **무료/유료 문장**은 카탈로그를 분리했습니다(중복 0). 유료 문장은 `src/content/paid-strings.js`(미리보기 전용)와 Worker `paid-copy.js`(정식 결제용)로 나뉩니다.
- **공유**는 `/api/share` → `/r/{code}`(CSPRNG 60bit, 30일 TTL, 폐기 토큰). 서버에는 일간·일지 index만 저장하고, URL·카드에 이름·생년월일·시간·성별·달력이 없습니다.
- **결제**는 `PaymentState{mode:'preview'}`로 분리했습니다. 미리보기에서는 `payment_complete`를 보내지 않고 “미리보기 잠금 해제”로 말합니다.

### (4) 인연 궤도 — 점수 대신 관계의 결

- 무료 사용자도 그대로 씁니다. 무료에서도 **유형 + 한 줄 + ‘이렇게 지내 보세요’** 까지 보여 줘 독립된 콘텐츠로 읽히게 했습니다(긴 해석만 유료).

### (2) 넣은 방식

- `vendor/manseryeok.js` — npm 배포본 `dist/index.mjs`(ES module)를 **브라우저 전역 `window.Manseryeok`용 IIFE로 감싼 사본**입니다. 마지막 `export {…}` 한 줄만 `return {…}`로 바꿨고 계산 코드는 손대지 않았습니다. 라이선스는 `vendor/manseryeok.LICENSE`(MIT).
- `index.html`에서 `vendor/manseryeok.js` → `saju.js` → `copy.js` → `app.js` 순으로 부릅니다. (빌드 도구·CDN 런타임 의존 없음)
- `saju.js`는 엔진 위의 **'사주 읽기' 계층**입니다: 지장간 · 십신 · 12운성 · 대운 · 오행 분포(8자 균등 → 100% 누적) · 도화살 · 시진 대표 시각 · 절입/시진 경계 판정 · 연애 타이밍 · **인연 궁합(`compatibility`)**.

### (3) 시주 관법 — 표준시가 기본, 진태양시는 안내

- 기본 명식은 **한국 표준시(KST)** 기준입니다. 폼이 시진(2시간) 단위 입력이라 시진 **한가운데 시각**을 엔진에 넣습니다(오시 → 12:30).
- 서울 진태양시는 경도 보정 **-32분**입니다. 이걸 적용하면 1995-04-12 11:30생이 **10:58(사시)** 로 넘어가 시주가 달라집니다. 관법이 갈리는 자리라 **기본값은 표준시로 두고**, 경계를 넘는 경우에만 명식 해설에 한 줄 안내를 붙입니다(`chart.hourEdge`, `chart.termEdge`).

## 4. 인연 궤도 — 나 중심 달 궤도 궁합

### (1) 궁합 계산 (`saju.js > compatibility`)

내 일간 오행과 상대 일간 오행의 **생·극 관계**로 기본 점수를 잡고, 천간합·육합·천간충·육충을 더하고 뺍니다.

| 관계 | 뜻 | 기본 |
|---|---|---|
| `gwiin` | 상대 오행이 나를 낳음 (나를 살리는 귀인) | 84 |
| `same` | 같은 오행 (비화) | 68 |
| `give` | 내가 상대를 낳음 (내가 챙기는 쪽) | 60 |
| `press` | 내가 상대를 누름 | 54 |
| `drain` | 상대가 나를 누름 (소모되는 인연) | 36 |

- 천간합(갑기·을경·병신·정임·무계) **+13**, 육합 **+8**, 천간충 **-8**, 육충 **-8** → 18~98로 자름.
- 궤도: **76점 이상 1궤도(찰떡·귀인)**, **56~75 2궤도(무난·보통)**, **56 미만 3궤도(거리두기·상극)**.
- 결과는 `{score, orbit, relation, meElem, youElem, tags, hap, yukhap, chung, evidence}`.
- **점수는 궤도 배치에만 쓰는 내부 값**입니다. 화면과 고객 데이터로는 숫자를 내지 않고, `orbitDetailParts()`가 `evidence[]`(일간·일지·천간합·육합·육충)를 넘겨 유료 상세·초대 카드에 ‘일주 근거’ 칩으로 보여 줍니다.

### (2) 궤도 지도 (`renderOrbit`)

- `viewBox 340×340`, 중심 `(170,170)`. 중심에 일간(예: `癸水`) + `나`, 반지름 **70 / 104 / 138**의 점선 궤도.
- 노드는 궤도별로 고르게 배치. 1궤도는 세이지, 2궤도는 황토, 3궤도는 먹 점선. 가운데 작은 점은 **그 사람의 일간 오행 색**.
- 이름은 위쪽 절반이면 노드 위, 아래쪽 절반이면 아래에 붙습니다.
- **노드를 누르면** 아래 풀이 상자가 그 사람이 나에게 주는 기운을 한 줄로 말합니다(`gwiin`/`same`/`give`/`press`/`drain` 문형 + 천간합·육합·육충 한 줄).

### (2-1) 관계 유형 다섯 (`C.ORBIT_TYPE`)

| relation | 유형 | 무료 (한 줄) | 유료 (상세) |
|---|---|---|---|
| `gwiin` 상대가 나를 낳음 | **충전냥** | 나를 충전해 주는 사이 | 왜 그런지 + 부탁해도 되는 이유 |
| `give` 내가 상대를 낳음 | **불꽃냥** | 내가 불을 붙여 주는 사이 | 돌아오는 길이 좁은 관계 + 몫 말하기 |
| `same` 같은 오행 | **거울냥** | 말 안 해도 통하는 사이 | 같이 가라앉을 때의 위험 + 거리 두는 법 |
| `press` 내가 상대를 누름 | **동료냥** | 내가 앞에서 끄는 사이 | 조언이 수업이 되는 지점 + 역할 나누기 |
| `drain` 상대가 나를 누름 | **티격태격냥** | 나를 누르는 사이 | 비밀을 나누지 않는 이유 + 횟수 정하기 |

범례도 궤도(1·2·3)가 아니라 이 다섯 유형으로 그리고, 인원수를 함께 셉니다. 상세 해석은 복채 1,900원 뒤에 열립니다.

## 9. 화면 / 기능

1. **입력(랜딩)** — 화투패 헤더 → 고양이 히어로 → 4칸 아이콘 바(팔자 고양이·천기팩폭·인연 궤도·천기부적) → `여기까지 무료` 안내 띠 → 먹선 박스 폼(오늘 물어볼 것 2×2). 초대 링크로 들어오면 히어로 아래에 `○○ 님의 초대` 띠.
2. **무료 천기(`#screen-free`)** — `민지 님의 팔자 고양이` → **일간 고양이 그림 + 유형 이름(안개냥) + 癸水 · 비·이슬 + 한 줄 정의 + 십성 한 줄 + 근거 칩(일간·오행 개수%·십성) + 해시태그 + 해설** → **천기팩폭** 띠 → **대표 성향 핵심 3** → **결과 카드(9:16·1:1)** → **사주명식·오행 분포 접기 카드** → **운 미리보기 3줄 → 1,900원 버튼 → 목차 5가지** → **인연 궤도**(예시 지도·관계 유형 5·친구 추가·초대) → 하단 고정 바.
3. **결제(미리보기)** — 종이 쪽지 시트: `미리보기 결제` 배지, `복채 1,900원`, `1,900원에 담기는 것` 5줄, 결제수단 3개(한 줄), 안내, **아래 붙박이 버튼**(`미리보기로 결과 보기`) → 고양이 로딩(2.4초) → 유료 결과. 카드값은 나가지 않습니다.

## 10. 토스페이먼츠 1,900원 결제 실제 연동 방법

현재는 `app.js`의 `doDemoPay()`가 2.4초 뒤 결과를 여는 데모입니다. 실제 결제로 바꾸려면:

### (1) 결제 준비
1. [토스페이먼츠 개발자센터](https://developers.tosspayments.com)에서 상점(MID) 발급 → **클라이언트 키 / 시크릿 키** 확인
2. 결제위젯 또는 결제창(API 개별 연동) 중 선택. 카카오페이·토스페이는 **간편결제 수단**, 카드는 **카드**로 노출됩니다.

### (2) 클라이언트 — `doDemoPay()`를 교체
```html
<script src="https://js.tosspayments.com/v2/standard"></script>
```
```js
async function pay(orderId, method) {
  const tossPayments = TossPayments('test_ck_...'); // 클라이언트 키
  const payment = tossPayments.payment({ customerKey: getCustomerKey() }); // 비회원은 ANONYMOUS
  await payment.requestPayment({
    method: method === 'card' ? 'CARD' : 'EASY_PAY',
    amount: { currency: 'KRW', value: 1900 },
    orderId,                                   // 서버에서 생성: NYANG_<uuid>
    orderName: '냥도사의 천기누설 한 장',
    successUrl: location.origin + '/payment/success',
    failUrl: location.origin + '/payment/fail'
  });
}
```
- 결제창을 띄우기 **전에** 서버에서 `orderId`를 만들고 금액(1,900원)을 DB에 저장하세요.
- `successUrl`로 돌아오면 `paymentKey / orderId / amount`를 받아 서버로 보냅니다.

### (3) 서버 — 승인 요청 (시크릿 키는 절대 프론트에 두지 마세요)
```js
// POST /payment/confirm
const res = await fetch('https://api.tosspayments.com/v1/payments/confirm', {
  method: 'POST',
  headers: {
    Authorization: 'Basic ' + Buffer.from(secretKey + ':').toString('base64'),
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ paymentKey, orderId, amount: 1900 })
});
```
- 승인 성공 시 **DB에 `paid=true` 기록** → 그때 결과(상세 풀이)를 내려주세요.
- 금액 위변조 방지: 요청으로 받은 `amount`가 주문서의 1,900원과 같은지 서버에서 반드시 비교.
- 실패/취소: `failUrl` 처리 + `GET /v1/payments/{paymentKey}`로 상태 재확인.

### (4) 결과 잠금 해제를 서버 기준으로
지금은 프론트 상태(`state.paid`)로만 잠금을 풉니다. 실제 서비스에서는 **상세 풀이 텍스트를 결제 전에 클라이언트로 내려보내지 말고**, 결제 승인 후 API로 받아 렌더링하세요(블러는 연출일 뿐, DOM에 있으면 개발자도구로 읽힙니다).

### (5) 환불·고지 (한국 전자상거래법)
- 1,900원 단건 결제의 경우 **청약철회 제한(디지털 콘텐츠 제공 개시)** 문구를 결제 버튼 위에 명시해야 분쟁이 줄어듭니다(결제 시트에 문구 자리 있음).
- 사업자라면 통신판매업 신고, 사업자정보 표시(상호·대표·주소·연락처)가 필요합니다.

```
         3문장 이내. '~냥'은 문단당 한 번만, 인사·마무리에.

[유저]   일간: 무토(戊土) / 오행: 목2 화2 토3 금0 수1 / 십신: 정관2 편재1 / 물어본 것: 재물운
```
